# 保卫水果：第一代功能原型

这是 OPP 项目中《保卫水果》的第一代历史版本，封存于 2026 年 10 月 14 日，版本为 v0.5.1。游戏是竖屏防守玩法：切换射手、蓄力射击，抵挡敌人并守护水晶。原型包含 3 章 9 关、3 档难度、三位射手的技能、增益卡、Boss、评分和本地存档。

## 目录

- `源码与素材/FruitDefense/`：从初代源码包展开的项目，包含 Godot + C# 源码、当时已有的素材、测试、需求和交接文档。
- `原始封存包/`：原始源码与素材 ZIP、Windows 完整离线开发 ZIP、原始说明、清单和校验记录。

这是历史快照，保留封存当时的占位美术及未完成功能。后来加入的界面、素材、肉鸽原型和 Unity 样板不属于此版本。源码包没有包括个人存档、生成缓存和项目外部的素材下载库；具体范围见原始封存说明与清单。

## Windows 试玩与开发

当前没有找到第一代独立 Windows 游戏安装包。Windows 离线开发 ZIP 包含项目、Godot .NET 和 .NET SDK 的离线压缩包，供 Windows x64 搭建开发环境并运行原型，并非游戏安装程序。

将 `原始封存包` 中的 Windows 离线开发 ZIP 解压到新的目录，保留解压后的 `FruitDefense` 与 `offline-tools` 相邻。然后依次运行 `FruitDefense/初始化开发环境.cmd`、`检查开发环境.cmd`、`启动保卫水果.cmd`。详细步骤和依赖见原始封存说明和项目内 `START_HERE.md`。不要解压覆盖正在开发的工程。

操作：1、2、3 或点击头像切换射手，按住发射区域并向目标反方向拖动，松开发射；空格暂停，R 重开。

## 手机版本

原型面向手机竖屏设计，包含触屏输入，但封存时尚未导出或实机验证手机安装包。本次在现有项目和交付目录中未发现 APK 或 AAB；也没有找到 iOS 安装包。离线开发包不包含完整的 Android 构建环境。

## 验证与素材

原始记录显示封存时通过 45 项规则检查和 27 项窗口检查；这是历史记录，不代表本次重新运行了游戏。本次核对了两个原始 ZIP 的 SHA-256，均与封存记录一致，源码 ZIP 的 CRC 检查通过。

项目包含参考和第三方素材，其权利与授权情况需要逐项核实；公开发布前应检查素材、字体和依赖的使用许可。此归档未附加新的开源许可证。
