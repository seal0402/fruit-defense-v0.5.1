# 技能需求模板

每个特殊技能可以复制一份。名称、参考图和一句效果描述就可以作为开始。

- 技能名称：
- 使用者：玩家全局技能 / 某个水果塔 / 某个怪物或Boss。
- 参考图片、视频或文字描述：
- 必须保留的视觉特征：
- 希望修改的视觉内容：
- 玩家怎么释放：点击按钮 / 选择位置 / 指定敌人 / 自动触发 / 其他。
- 生效范围：单体 / 圆形 / 直线 / 全屏 / 其他。
- 实际作用：伤害 / 减速 / 冰冻 / 击退 / 恢复 / 其他。
- 生效时机与持续时间：可后续确定。
- 冷却时间与资源消耗：可后续确定。
- 是否影响Boss、是否允许效果叠加：可后续确定。
- 视觉阶段：预告范围、蓄力、发射或展开、命中或持续、消散。
- 音效、镜头震动或其他反馈：可后续确定。
- 图标与冷却显示要求：
- 其他要求：

技能完成时检查三件事：画面表现符合设定，实际作用符合规则，资源扣除和冷却正确。伤害结算与动画播放需要同步，避免只出现特效而未生效，或同一次攻击重复结算。
