# 角色需求模板

每个角色可以复制一份。可以只写名称、附上图片，再说明想改哪里。

- 角色名称：
- 角色类型：水果塔 / 普通怪物 / Boss / 守护目标 / 其他。
- 原图文件或图片说明：
- 必须保留的特征：
- 希望修改的部分：
- 风格、颜色和视角要求：
- 是否需要透明背景或拆分身体部件：待判断 / 需要 / 不需要。
- 需要的动作：待机 / 移动 / 攻击 / 受击 / 死亡 / 其他。
- 玩法作用或特殊能力：
- 攻击方式、伤害、范围、攻击间隔等：可后续确定。
- 怪物血量、移动速度、消灭奖励等：可后续确定。
- 希望在游戏中的大小或参照对象：可后续确定。
- 其他要求：

图片修改、动画制作和游戏行为分别记录。静态图片完成后，继续检查它是否适合游戏视角、实际显示尺寸以及所需动作。
