# 手机竖屏美术提示词与交付说明

日期：2026-10-14。用户已确认最终游戏用于手机，采用竖屏。以下以 9:16、1080×1920 为背景制作基准；人物采用独立正方形透明画布。坐标是美术留白建议，最终可按手机界面调整。

本包竖屏背景使用内置 image_gen 生成，实际为 941×1672、RGB PNG，接近 9:16，作为构图与风格参考。它不是已导出的 1080×1920 文件。先前白子样图均为 1254×1254、RGBA PNG。当前交接不要求其他作图 AI 使用同一种工具。

| `参考图片/01_shiroko_original.webp` | 白子的脸、服装、武器、发型与识别特征 |

生成背景时只上传背景参考图。生成白子时上传原立绘、相应姿态样图和竖屏背景，明确告诉 AI：背景图只作相机与光照参考，不画进人物图。

建议顺序：背景 → 一个角色的上场待机母版 → 同角色蓄力 → 发射 → 候场。选定一个母版后，持续以它作为参考或编辑目标；不要每个动作都只从文字重新生成。先核验一套角色，再用同规格扩展其他角色。

## 1. 竖屏战斗背景提示词

上传本包竖屏背景作为参考，复制以下整段：

```text
为手机竖屏 2D 防守射击游戏制作一张纯环境背景底图。使用上传图片作为场景风格、建筑设计、配色和构图参考，重新绘制高质量成品。

画幅与输出：严格竖向 9:16，1080×1920，PNG。图片铺满整张画布，保持物体正常比例。

相机：高位鸟瞰俯视，相机视线与地面的夹角约60至65度，近似正交投影。可以看到地面与两侧局部屋顶，地面道路从画面上方一直延续到下方。上下物体采用相同世界尺度，道路边缘与铺砖保持近似平行，不出现明显的远处消失点。

场景：清爽明亮的现代学院都市街道或步行广场，精致日式动漫2D游戏背景。浅蓝灰与冷白铺装、青蓝色建筑细节、少量绿色树木，左上方柔和日光。材质清楚但细节克制，地面不要有过强纹理和大面积黑影，要能衬托缩小后的人物、子弹和特效。

空间分配：中央约75%的宽度保持开阔地面；建筑、树木、花坛与栏杆集中在两侧窄边缘。顶部约0至12%保留安静的入口与界面留白；约12至65%作为开阔战斗区；高度约68%处留一条水平通畅地面带，未来单独放防线；约72至87%留作射手区域，中间是上场位置，左右两侧各有候场空地；约88至94%为核心位置；最下方约6%保持安静，方便叠加触控界面。只通过环境留白体现这些空间，不画分区框、位置标记或平台。

只画环境底图。人物、敌人、防线、水晶、按钮和特效会在游戏中独立添加。

禁止：仰视、平视街景、天空、地平线、强透视消失点、鱼眼镜头、横版构图、把横图硬拉成竖图、黑边、模糊补边、场景中间的大型障碍物、人物、车辆、枪械、隔离网、水晶、UI、按钮、血条、文字、logo、水印、网格、标注、粒子特效。
```

如果作图工具将宽高比与提示词分开设置，在工具中同时选择 9:16 和竖向画布。提示词不能保证工具一定按指定像素导出，下载后核对真实尺寸。

## 2. 白子人物公共提示词

每次生成白子，使用下面的公共提示词，再追加第 3 节中的一个状态提示词。每次只输出一个状态的一张图片。

```text
为手机竖屏2D防守射击游戏制作砂狼白子的独立人物精灵图。

参考用途：原立绘用于锁定人物身份、服装与武器；已选定的战斗母版用于锁定人物比例、相机和画风；竖屏背景只用于相机与光照参考，不画进人物图。

角色识别特征：银灰色短至中长层次发型，竖起的狼耳，耳尖深色、耳内浅色；青蓝色眼睛，交叉的青色发夹，头顶细薄的青色椭圆分段光环；青蓝色围巾，深蓝校服外套、白衬衫、青色领带、深色格纹百褶裙；白色长袜、灰黑运动鞋、青色鞋带和黄绿色鞋底；黑色青蓝条纹单肩书包。白灰色现代步枪，青色细节，黑色枪管与弹匣，保持参考图中的枪械型号外形和长度。左手黄绿色露指手套，右手裸手。服装、发夹、手套、书包与武器的左右关系正确。

风格：精致日式动漫2D游戏精灵，约4头身的适度简化比例，干净清晰的线稿和赛璐璐明暗，大形体明确，缩小后仍能辨认。表情冷静自然，肤色与衣料颜色遵循参考图。各状态采用同一人物骨架尺寸与头部大小，不重新设计人物。

相机：固定高位俯视，相机视线与地面的夹角约60至65度，近似正交投影；能看到头顶、耳朵上面与肩部上面，脚部有符合俯视的缩短。更换动作时相机不动、镜头不缩放；只改变人物姿态或身体朝向。柔和光源始终来自屏幕左上方。

画布与对齐：1024×1024，单个完整人物，实际透明背景的RGBA PNG。完整保留耳朵、固有光环、枪口、书包、围巾和双脚，四周至少留约8%安全边距。双脚接地位置的中心作为地面基准点，固定在画布约(512,860)；各状态保持同一地面基准点与同一世界尺度。蹲下时头部可以自然降低，但脚底基准不移动，不通过整体缩放来凑构图。

人物本体独立成图。保留角色固有青色光环；阴影、枪口火花、蓄力能量、弹壳、弹体与粒子另作图层。

禁止：背景场景、地面、脚下阴影、棋盘格假透明、UI、文字、水印、多人、四格拼图、额外肢体、畸形手、双枪、枪械变形、发夹与手套换边、改变服装、改变头身比、裁掉脚或枪口、运动模糊、烟雾、额外发光能量球与粒子效果。
```

画布参数可换成 1536×1536 等工具支持的正方形尺寸，但同一角色全套必须一致，基准点按(50%宽,84%高)等比例换算。上述1024像素约860处是约84%的近似值，不是要求以不同数字反复微调构图。

文件名：`shiroko_active_idle_NW_v001.png`。

```text
状态：上场待机，已经站在中央发射位置，准备向敌人攻击。
身体朝屏幕左上方，从固定俯视相机看见背侧三分之四。头部跟随身体，不回头看镜头。双脚稳定分开，双膝轻微弯曲，上半身自然直立。右手握枪柄，左手托住枪身前部，步枪处于低位准备姿态，枪口指向左上方，尚未贴紧瞄准或发射。围巾、发梢和书包自然下垂。
整体轮廓平稳，呈现能立即开始攻击的准备状态。保持公共提示词中的相机、体型、画布、脚底基准和武器设计。
```

## 4. 换其他角色的方法

保留公共提示词中的相机、光照、画布、比例、对齐与分层要求。将身份段替换为：

```text
角色名：[角色名称]。
以原始立绘锁定脸型、发型、发色、眼睛、固有光环、服装轮廓、配饰、鞋袜、持枪方式和武器类型。保留以下关键特征：[列出最重要的3至6项]。人物转身后仍然是同一角色，手套、发夹、饰品和武器保持正确左右关系。
武器：[普通步枪/狙击枪/霰弹枪等]。动作按武器的正确握持方式设计，保持同一角色所有状态的武器型号与长度一致。
```

再分别追加四个状态提示词。不同武器的持枪和后坐动作应相应调整，不把所有角色的枪都画成白子的步枪。

## 5. 需要自由瞄准时的方向扩展

当前白子战斗样图主要朝左上方。四种状态不等于覆盖所有方向。如果正式玩法保留自由瞄准，可先为上场待机、蓄力、发射这三种战斗姿态制作八方向关键图；候场按实际摆放需要保留1至2个方向。八方向的标记是屏幕方向，不是剧情中的地图朝向。

| 后缀 | 屏幕朝向 |
| --- | --- |
| N | 上 |
| NE | 右上 |
| E | 右 |
| SE | 右下 |
| S | 下 |
| SW | 左下 |
| W | 左 |
| NW | 左上 |

追加给作图 AI：

```text
将该状态的人物身体、头部与武器真实转向屏幕[方向]。相机、光源、人物实际大小、画布和脚底地面基准保持不变。根据新朝向重新绘制可见的正面、侧面或背面结构。服装、发夹、手套与武器左右关系保持正确。不要将整张二维人物图片平面旋转，也不要水平镜像来替代真实转身。输出单独的一张透明PNG。
```

先完成一个方向的一套状态确认风格，再扩展方向，避免一次制作大量不一致的图片。这里交接的是静态关键姿势；连续动画所需的动作过渡、帧数和循环节奏另行制作。

## 6. 图片交付要求

- 背景：独立 PNG，竖屏9:16，目标1080×1920；只有环境，不含人物、核心、防线与界面。
- 人物：每角色、每状态、每方向分别一张实际透明 PNG；同一角色全套画布、物理比例与脚底基准一致。
- 完整保留枪口与脚，边缘无明显白边、杂点或裁切。棋盘格只能是软件预览，不能被画进图片本身。
- 人物、地面阴影与粒子分层。若工具无法生成实际透明通道，请明确标注“背景尚未抠除”，保留原始文件。
- 提供原始分辨率图片，避免只交聊天截图、拼图或有损压缩后的缩略图。可将全部PNG和简短状态清单放进一个ZIP。
- 参考命名：`bg_street_portrait_v001.png`、`shiroko_active_idle_NW_v001.png`、`shiroko_charge_NW_v001.png`、`shiroko_fire_NW_v001.png`、`shiroko_reserve_idle_SE_v001.png`。

素材回传后，按实际图片校准脚底与枪口位置、生成游戏加载版本，并检查缩小到手机显示尺寸后的清晰度和层次。
