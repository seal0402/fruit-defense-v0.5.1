每关 3 波，保留轻松、标准、挑战三档。多名首领分布在不同波，依次出场。后两章增加小兵生命、每波数量和少量速度；同时通过章节增益形成成长。存活敌人同时最多 6 名，不用无限堆怪提高难度。

三章首领使用同一组“蓄力重击、伤害打断、半血援兵”机制；第二章名称为铁甲掠夺者，第三章为裂隙统领。生命分别为 600 / 780 / 960，护甲为 0 / 3 / 5，防线重击为 45 / 50 / 55。当前是同机制的加强型首领，后续可按素材设计独立招式。

## 评分以防线为准

仅在通关时授星：

- 3 星：本关防御网从未受到伤害。
- 2 星：防御网受过伤害，但没有破碎。
- 1 星：防御网已破碎，仍守住水晶并完成关卡。
- 失败：水晶生命为 0，0 星，不算通关。

防线记录 EverDamaged 历史标记，今后即使加入修复，也不能通过修满血洗回 3 星。结算展示本次星级，战绩保存同关同难度的最高星级。

0.4 的旧星级以水晶剩余生命为标准，无法换算成新星级。旧积分与通关次数保留；旧星级保存在 LegacyStars，战绩显示“待重评”。首次按新规则通关后开始记录新星级，避免混用标准。

## 增益卡如何掉落和选择

每关前两波清完后，自动拾取本波掉落，展示 3 张不同的卡，玩家选 1 张。选卡期间敌人、弹药、冷却、战斗时间和下一波倒计时冻结；选定后才继续。每关取得 2 张，一章连续打完可取得 6 张。末波直接结算，不额外生成一组无法使用的卡。

增益对三位射手共同生效，选卡和结算时显示本章累计加成。卡片名称、数值和效果都是真实规则，不是只改显示。当前没有独立的地面卡牌捡取操作；采用清波自动拾取，减少手机竖屏上额外点击。

| 卡片 | 效果 | 叠加规则 |
| --- | --- | --- |
| 敏捷装填 | 攻速 +10% | 按加法累计 |
| 极速装填 | 攻速 +20% | 按加法累计 |
| 双倍弹药 | 每次发射的弹药数量 ×2 | 1 → 2 → 4 → 8，达到 8 发后不再掉落该卡 |
| 火力强化 | 普通及蓄力技能伤害 +20% | 按加法累计 |
| 锋利弹头 | 每发直击与有效溅射基础伤害 +5 | 可叠加 |
| 精准打击 | 暴击率 +10%，暴击为 2 倍伤害 | 暴击率上限 100%，达到上限不再掉落 |
| 连锁闪电 | 每发首次命中向附近另一个敌人传递 18 点伤害 | 唯一能力，取得后不重复掉落 |
| 燃烧弹药 | 命中后每秒灼烧 8 点，共 3 秒 | 唯一能力；重复命中刷新时间，不无限叠加燃烧层数 |

攻速 +10% 再加 +20% 等于总攻速 +30%，发射间隔 = 原间隔 ÷ 1.3。例如快射 0.22 秒变为约 0.169 秒。攻速不缩短蓄力技能自身的 10 / 14 / 16 秒冷却。

伤害按“（基础伤害 + 固定额外伤害）×（1 + 百分比伤害加成）× 暴击倍率”计算，再扣敌人护甲。原本没有溅射的射手不会因为锋利弹头新增溅射。直击目标不会再重复承受本次溅射。

多发弹药为轻微扇形真实弹体，各自独立碰撞；快射蓄力三连也会翻倍，最多每轮 3 × 8 = 24 枚。每枚独立判定暴击，贯穿沿途每敌人仍只命中一次。闪电只传递一次，传递伤害和灼烧不递归触发其他附加效果。

当前闪电与灼烧采用固定伤害，依然受目标护甲影响；火力卡和暴击加强直击/溅射，不放大这两种附加伤害。这些数值均可继续调整。

## 同章连续闯关与存档

主页“关卡选择”可切换章节和三个子关。本功能版全部开放，便于测试。

- “开始游戏”或“进入关卡”：从所选关卡开始一段新的章节挑战，增益从零累计。
- 通关后“下一关 · 保留增益”：携带当前增益进入本章下一关。每关防线和水晶恢复，评分按本关重新计算。
- “再来一次”或战斗中按 R：恢复到本关进关时的增益，丢弃失败/退出尝试中获得的新卡，不能无限刷卡。
- “继续章节”：恢复保存的章节检查点及当时增益。中途退出/关程序后，从本关开头重新打；已经完成上一关则继续下一关。
- 本章第三关完成：本章结束，清除继续章节检查点。开始其他章节重新累计，旧关卡最高分和星级保留。
- 训练场仍不掉落卡、不计战绩，也不继承章节加成。

检查点保存的是“进关快照”，不是实时战场；没有保存敌人位置、尚未完成的波次或待选卡。一个存档当前保留一段章节挑战，主动开始新挑战会替换旧检查点。

## 建议试玩顺序

1. 主页 → 关卡选择 → 第 1 章 → 果园初战 → 进入关卡。
2. 清完第一波，观察三选一和冻结的倒计时；选卡后检查快射间隔或实际弹药数量。
3. 清完第二波再选卡，验证加成累计；完成本关查看防线对应星级。
4. 点“下一关 · 保留增益”，确认加成保留而防线与水晶恢复。
5. 新关选卡后按 R 重试，确认恢复进关加成；退出回主页点“继续章节”检查同样的快照恢复。
6. 切换第三章终局围城，体验三波首领；直接选后期关卡从零起步会比完整章节成长更难。
