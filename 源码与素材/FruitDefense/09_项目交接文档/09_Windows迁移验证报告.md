# Windows迁移验证报告

日期：2026-10-14。验证对象为0.3竖屏原型和新增迁移工具。此次是在同一台Windows电脑的全新目录验证，不是已经访问或测试了Grok Bot云电脑。

## 验证条件

- 创建新的FruitDefense副本，未复制原项目的.godot、bin、obj或.local缓存。
- 从官方Windows离线压缩包重新解压.NET SDK 10.0.402和Godot .NET 4.7.2。
- 两个压缩包的SHA512与官方清单一致。
- 设置FRUITDEFENSE_PORTABLE_ONLY=1，禁止查找原D:/GodotDev。
- DOTNET_ROOT、DOTNET_CLI_HOME、NUGET_PACKAGES均指向新目录。
- 首次NuGet缓存为空，源只配置新项目tools/packages相对目录。
- 实际使用Windows自带powershell.exe执行迁移入口；脚本采用UTF-8 BOM兼容中文路径。
- 图形测试入口等待进程完成并检查退出码，避免Windows GUI程序提前返回。
- 显式关闭.NET SDK自动追加用户PATH和生成开发证书，缓存保留在项目内部；验证中新增的临时PATH项已撤回。
