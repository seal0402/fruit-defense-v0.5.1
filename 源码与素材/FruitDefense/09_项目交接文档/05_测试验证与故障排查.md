# 测试验证与故障排查

## 当前证据

原机Windows上的游戏验证为21项规则加17项Godot图形/输入，共38项通过。记录在06_预览与测试/试玩记录。手机竖屏、触屏拖拽、多指隔离、返回通知、小暂停、设置冻结、主页返回、反向拦截和三档难度均有检查。

触屏通过Godot事件注入验证，不等于手机实机测试。慢节奏通关通过真实拉弓输入、0.7秒一发、每四发主动偏离一次，游戏时钟加速推进；59发、15击杀、核心8/8，约76.7秒。它不保证任何玩家都能过关，也不是帧率测试。

迁移包本轮另做独立目录、空NuGet缓存、关闭旧D盘回退的验证，结果写入迁移验证报告。Linux/macOS脚本不是在这些系统实机上跑过的证据；接手后需重新验证。

## 运行

Windows有桌面：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Project.ps1 -Action Test
```

Windows只检查规则：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Project.ps1 -Action Test -RulesOnly
```

Linux/macOS：

```bash
bash tools/project.sh build
bash tools/project.sh test
bash tools/project.sh import
# 有图形显示时再执行
bash tools/project.sh test-ui
```

正常启动不会执行自动输入；必须明确传入--integration参数才会运行界面检查。测试结束游戏自行退出，失败返回非零状态。不要用受控999伤害的弹窗检查冒充正常攻击通关。

## 常见故障

| 现象 | 检查与处理 |
| --- | --- |
| SDK未找到或只有Runtime | Doctor检查dotnet路径及--list-sdks；安装10.0.402 SDK |
| 找不到Godot.NET.Sdk | 确认tools/packages四个nupkg存在，NuGet.Config相对路径正确，工作目录为game |
| Godot不能加载C# | 确认是mono/.NET版本及4.7.2，先编译再启动 |
| 迁移后仍访问旧D盘 | 查看Doctor输出；优先初始化tools本地工具，设置PORTABLE_ONLY禁止兼容回退 |
| 无DISPLAY、GL或图形设备 | 先跑build/test/import；补充显示环境后再跑图形检查，不能声称截图成功 |
| 中文方块或字体不一致 | 提供云系统可用CJK字体或正式可分发字体，当前SystemFont名称偏向Windows |
| macOS不能直接运行应用 | 使用系统允许的官方应用打开流程，核对签名/下载来源，工具不自动禁用安全设置 |
| Linux提示Permission denied | 使用bash tools/project.sh；核对Godot与dotnet执行权限 |
| setup中途退出后目录不为空 | 检查失败原因和目录内容，脚本不自动递归清理；保留原图与源码 |
| 图片放入assets仍显示水果 | 素材尚未引用，按04文档接入表现层 |
| 入侵次数和核心生命不同 | 正常：顶部当前波，底部水晶剩余/最大生命 |
| 切换窗口后弓弦被取消 | 设计如此，防止失焦后残留射击 |
| ZIP解压报错或文件缺失 | 先对照SHA256SUMS.txt检查整个压缩包，再使用MANIFEST.sha256核对项目文件 |

缓存可重新生成；不要把历史横屏截图视为当前竖屏效果。新修订需要记录新结果，不直接沿用旧版38/38结论。
