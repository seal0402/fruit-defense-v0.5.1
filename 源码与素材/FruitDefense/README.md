# 保卫水果项目资料库

迁移后以解压得到的FruitDefense目录为根，不需要旧电脑路径。先读[START_HERE](START_HERE.md)，完整交接见[文档导航](09_项目交接文档/00_交接总览与文档导航.md)。

这里保存素材、开发资料与游戏工程。当前0.5.1功能模拟版面向手机竖屏：3类射手及蓄力技能、3类小兵和1名BOSS、3章9关、三档难度、可叠加增益卡、主页/资料/图鉴/记忆大厅/战绩、本地存档、触屏拉弓和小暂停菜单。正式画面与音视频等待素材接入，目前在Windows预览，手机安装包尚未导出。

三档难度已整体降低，最新数值和验证见[0.5.1难度说明](09_项目交接文档/12_整体难度下调0.5.1.md)。

章节、增益、评分与详细试玩顺序见[功能模拟版0.5](09_项目交接文档/11_章节增益与防线评分0.5.md)。主页和基础技能的补充说明见[0.4功能说明](09_项目交接文档/10_功能模拟版0.4与试玩路线.md)。之前制作的迁移ZIP为0.3快照，未自动更新。

## 现在试玩

新设备先按[启动指南](09_项目交接文档/01_新设备与云电脑启动指南.md)准备环境，再双击[启动保卫水果.cmd](启动保卫水果.cmd)，点击“开始游戏”。按1、2、3或点击头像切换射手，按住发射口向目标反方向拉弓，松手发射。空格暂停，R重开。

用户于2026年10月14日确认：**最终游戏用于手机，采用竖屏**。当前0.5.1版已经实现竖屏布局和触屏事件处理，在Windows预览验证；手机实机适配与安装包后续完成。美术按[手机竖屏美术约定](02_需求与参考/手机竖屏美术约定.md)准备。早期选型记录见[技术路线说明](技术路线说明.md)，当前工程环境见[游戏目录说明](game/README.md)。

当前玩法采用从上向下推进的敌人、底部隔离网、留在发射区域的可切换射手与独立弹药。基础攻击分为普通、狙击贯穿和霰弹直击加溅射，每名射手独立恢复；敌人触碰水晶后扣1点核心生命。具体规则见[玩法与原型说明](02_需求与参考/保卫水果_玩法与原型说明.md)，分工、素材与原型成果见[下一步执行清单](02_需求与参考/下一步执行清单.md)。已加入三类蓄力技能，仍保留其余技能扩展位置。开发工具按要求准备到 `D:\GodotDev`。

## 制作过程与成品位置

| 文件夹 | 用途 |
| --- | --- |
| `02_需求与参考` | 美术方向、玩法、角色、技能及关卡说明 |
| `03_制作中` | 修改中的图片、角色部件、动画和特效版本 |
| `04_处理完成` | 检查通过的素材成品，作为后续导出和调整的来源 |
| `game` | Godot工程目录；`assets` 存游戏实际加载的素材，`scenes` 存场景，`src` 存C#代码，`resources` 存引擎资源，`config` 存规则配置 |
| `06_预览与测试` | 游戏截图、动画预览、试玩问题和性能记录 |
| `07_游戏交付` | 可运行游戏、安装包和演示视频 |
| `08_课程报告` | 设计报告、类图、流程图和答辩资料 |

处理完成的角色目录与原始角色分类对应。`04_处理完成/动画序列` 另有待机、移动、攻击、受击、死亡子目录；技能施法动画及效果可按技能名放入 `04_处理完成/技能特效`。

## 文件流转约定

1. 原图保留在 `01_你提供的素材`，处理结果另存版本。
2. 中间结果放入 `03_制作中`，预览放入 `06_预览与测试`。
3. 确定采用的素材放入 `04_处理完成`，记录尺寸、用途和版本。
4. 生成适合游戏加载的版本后，放入 `game/assets`；它可能与成品母版在尺寸、图集组织或压缩方式上不同。
5. 实际测试后，把可运行版本及配套资源放入 `07_游戏交付`。

游戏内部文件建议使用稳定的英文名称，例如 `tower_apple_idle_v001.png`、`skill_frost_impact_v001.png`。这些仅为命名示例，不代表已确定角色或技能。项目资料目录使用中文，方便查找。
